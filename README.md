# Videomaker Studio — браузерный видеоредактор

[Открыть приложение](https://surniiyka-cloud.github.io/Videomaker/)

Videomaker — самостоятельный браузерный редактор для работы с генерациями Runway и музыкой. Исходники хранятся в браузере (IndexedDB), а не публикуются в GitHub.

## Сейчас работает

- Импорт видео и музыкальной дорожки целой папкой или по одному файлу.
- Таймлайн: порядок клипов, начальные и конечные точки, жёсткие склейки / растворения, зум, музыкальная дорожка.
- Предпросмотр с музыкой, сохранение проекта и медиа между перезагрузками на том же сайте/браузере.
- Импорт/экспорт JSON и ZIP-пакета с исходниками для ChatGPT.
- Экспериментальный AI Director: Transformers.js + CLIP для классификации первого/последнего кадра, независимый анализ экранного смещения по нескольким кадрам.
- «Подобрать границы»: предлагает небольшие корректировки стыков и **не меняет таймлайн без подтверждения**. Можно отменить изменения.
- Цветокоррекция каждого клипа: яркость, контраст, насыщенность, теплота.
- «Согласовать цвет клипов»: по средней яркости и контрасту кадров, с возможностью отмены. Это эвристика, не профессиональный цветовой матчинг.
- Встроенный экспорт WebM (MediaRecorder, реальное время) с цветокоррекцией, зумом и музыкой.

## Как использовать

1. Откройте сайт в актуальном Chrome или Edge и загрузите папку с клипами и музыкой.
2. Укажите порядок сцен на таймлайне.
3. Запустите «Анализировать сцены», затем «Анализировать движение» (ИИ-модель при первом запуске загружается из интернета).
4. Для чернового монтажа используйте «Подобрать границы», изучите предложения и только затем нажмите «Применить».
5. В блоке настроек выбранного клипа отрегулируйте цвет и масштаб. «Согласовать цвет клипов» выравнивает общий тон и может быть отменено.
6. Проверьте переходы в предпросмотре, сохраните JSON/ZIP, экспортируйте WebM.

## Ограничения

- Transformers.js не является автономным режиссёром. Он распознаёт содержание кадров, но не гарантирует плавности камеры или точности склейки. Анализ движения приближённый.
- Автоматическое согласование цвета основано на статистике среднего кадра, а не на покадровой цветовой модели. При сильных световых эффектах его надо проверять вручную.
- Формат экспорта непосредственно из браузера — **WebM 1280×720**. При необходимости доступен дополнительный `render_project.py` на FFmpeg для MP4 1920×1080 из ZIP-пакета. Это необязательный инструмент, он не запускается на GitHub Pages. FFmpeg-коррекция цвета близка, но не пиксельно идентична CSS-фильтрам.
- Увеличение цифрового кадра не восстанавливает потерянное разрешение.
- IndexedDB зависит от квоты и настроек браузера. Рекомендуется периодически сохранять ZIP/JSON.
- Бесплатный браузер не предоставляет вычислительный сервер для тяжёлых видеомоделей. При первом запуске Transformers.js может скачать модель; обработка может быть медленной.

## Архитектура и развитие

- `index.html` — браузерный редактор, предпросмотр, монтажная шкала, WebM, IndexedDB.
- `ai_director.js` — локальная семантическая классификация кадров через Transformers.js.
- `motion_analysis.js` — приблизительная оценка экранного смещения.
- `render_project.py` — дополнительный рендер из ZIP через FFmpeg.
- `ARCHITECTURE_AI.md` — план поэтапного перехода к компонентам профессионального монтажного редактора.

FreeCut пока не интегрирован как кодовая база: мы лишь изучили возможность переноса. Для настоящего видеоредактора с ключевыми кадрами, модульным таймлайном и детерминированным MP4-экспортом необходим отдельный этап переработки.

## Конфиденциальность

Не добавляйте реальные фотографии людей и исходные видеоролики в публичный репозиторий. Медиа остаются в локальном хранилище браузера, пока пользователь сам не передаст их.

## Новое в v4.12.1: черновой монтаж и очистка

В инспекторе доступна секция **«AI Director · Черновой монтаж»**:

- Выбирайте сцены, которые надо исключить из монтажа; исходные файлы не удаляются.
- Для нежелательного участка внутри ролика введите время начала/конца **в секундах самого источника**. Приложение разделит сцену на два фрагмента и пропустит указанный участок; после этого может образоваться заметная склейка. Никакого восстановления пикселей или удаления объекта без следа здесь нет.
- Кнопка «Найти визуальные аномалии» отмечает возможные одиночные вспышки и скачки изображения. Плащ, дефект одежды или лишний объект без резкого скачка алгоритм может не обнаружить. Предложенные диапазоны требуют человеческой проверки.
- Доступны переходы: жёсткая склейка, короткое затемнение, вспышка (0,3 с), либо консервативное автоматическое решение. Ручные переходы доступны также в списке клипов. Эффекты включаются в предпросмотр и экспорт.
- Предложение можно просмотреть, принять или отменить. Во время предпросмотра автосохранение блокируется. После принятия доступна «Отменить подгонку».
- Автомонтаж пока **не** распознаёт семантически плохие действия, не строит новые кадры Runway, не заменяет предметы в видео и не заполняет всю песню недостающими сценами. Сюжетный порядок сохраняется.


## v4.13.0 — экспериментальный смысловой AI Director

Основная кнопка **«ИИ-режиссёр: анализировать автоматически»** запускает браузерную модель описания изображений и анализирует пять моментов каждого видеоклипа. Смотрит, не появляется ли кратковременное семантическое расхождение, одновременно сопровождаемое резким изменением картинки и возвратом к предыдущей композиции. Составляет предложенный монтаж без ручных таймкодов; пользователь может посмотреть и применить черновик целиком или отклонить его. Ручные инструменты перемещены в дополнительные настройки.

**Ограничения:** используется image captioning (Xenova/vit-gpt2-image-captioning), а не полноценная модель рассуждения по видео. Плащ, неправильная геометрия тела, сюжетная ошибка или неверное движение камеры могут остаться незамеченными. Модель может ошибочно описать кадр. Нельзя обещать, что приложение само определяет, что «не должно быть» в истории, без контекста сценария и визуального эталона героя. Результат никогда не применяется без проверки. Источники остаются в браузере. Требуется интернет для начальной загрузки модели; скорость зависит от устройства. Удаление объекта с восстановлением видеоряда (video inpainting) **не реализовано**. Для действительно автономной видеомодерации понадобится модель понимания последовательностей и, для точечного удаления объектов, отдельный ресурсоёмкий inpainting-движок.

## v5.1.1 — основная кнопка «СМОНТИРОВАТЬ КЛИП»

Новый единый сценарий запускает в одном действии (1) анализ ударов музыки, (2) экспериментальное описание кадров браузерной моделью с дополнительной перепроверкой обнаруженных противоречий, (3) сравнение пограничных кадров сцен, (4) глобальный подбор переходов с учётом накопленного перекрытия клипов и музыкальных точек. Собранный черновик сразу воспроизводится **только до конца доступных видеоклипов**. Затем пользователь подтверждает монтаж или восстанавливает исходный вариант. Экспериментальные ручные инструменты скрыты под раскрывающимся разделом.

Алгоритм **не удаляет фрагменты только потому, что модель написала «man → woman»**, не меняет существующий сюжетный порядок, не выдумывает отсутствующие сцены, не применяет автоматический цифровой зум и не делает video inpainting. Он предпочитает жёсткие склейки и осторожно выбирает короткое затемнение/вспышку лишь при достаточно выраженных визуальных изменениях. Не стоит обещать профессионально идеальный монтаж: настоящий контроль действующих лиц, движения предметов и монтаж по смыслу потребует более сильной видеомодели и, вероятно, отдельного вычислительного сервера. GitHub Pages сам по себе такой сервер не предоставляет.

Результат предпросмотра не записывается в автосохранение до нажатия «Принять монтаж»; во время предпросмотра отключены основные команды, меняющие порядок клипов. MP4 доступен только в браузерах, где поддерживается запись такого формата.
