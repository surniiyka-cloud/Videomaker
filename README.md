# Videomaker — AI Music Film Studio

Браузерная монтажная для работы с видеогенерациями Runway, Kling, Veo и музыкальными клипами. Всё обрабатывается **локально в браузере**, без загрузки медиаданных на сервер.

## Запуск

1. Скачайте `index.html` и откройте в актуальном Chrome / Edge.
2. Или включите **Settings → Pages → Deploy from a branch → main / (root)**. Через некоторое время приложение будет доступно по адресу `https://surniiyka-cloud.github.io/Videomaker/` (после успешного развёртывания).
3. Добавьте исходные видео, затем WAV/MP3.
4. Переставьте клипы, настройте обрезку и переходы, проверьте конец/начало.
5. Нажмите «Лист перехода PNG», чтобы получить пару референсов для следующей генерации.
6. Экспортируйте черновой монтаж в WebM (реальное время).

## Доступные возможности (MVP)

- Загрузка видео и музыки, предпросмотр.
- Извлечение крайних кадров и скачивание PNG.
- Таймлайн, обрезка, порядок клипов, переходы (cut / dissolve).
- Последовательная авторасстановка клипов.
- Грубая оценка музыкальных всплесков (не распознавание слов и не монтаж по сюжету).
- Экспорт WebM через MediaRecorder.
- Сохранение проекта JSON.

## Ограничения

- Браузер должен поддерживать видео-кодек загруженного файла. MOV / HEVC может не воспроизводиться.
- JSON сохраняет структуру, **не медиафайлы**; после загрузки проекта нужно снова выбрать исходники с теми же именами.
- Экспорт в WebM идёт в реальном времени и зависит от производительности компьютера / поддержки браузера; MP4/H.264 не гарантируется.
- Перекрытие кадров посредством dissolve **не восстанавливает** геометрически непрерывную съёмку; для таких переходов требуется подготовка изображений или дополнительная генерация.
- Музыкальные акценты определяются эвристически по энергии сигнала; синхронизацию с текстом и точные решения монтажа следует уточнять вручную.
- Приложение не имеет серверного хранилища и не предоставляет ChatGPT прямой доступ к локальным файлам браузера. Для совместной работы отправляйте PNG листа перехода, JSON проекта или видео в чат.

## AI-отчёт по монтажу (новая функция)

Кнопка **«↓ AI-отчёт по монтажу»** создаёт в браузере PNG-листы (по 5 клипов на страницу, 5 точек каждого клипа: начало, 25%, 50%, 75%, конец) и JSON с точным порядком, входными и выходными точками, длительностями и параметрами переходов. Отправьте PNG и JSON в чат для планирования следующей генерации. Если требуется анализ собственно движения между указанными точками, дополнительно прикрепите исходный MP4 или экспортированный участок монтажа.

**Конфиденциальность:** приложение не загружает видео в публичный GitHub-репозиторий. Видеоролики с реальными людьми и крупные исходники не стоит публиковать в открытом репозитории. Для автоматической передачи медиа потребуется отдельное защищённое хранилище и авторизация.

## Автосохранение (IndexedDB)

Приложение автоматически хранит **исходные видео, аудио и состояние таймлайна** в IndexedDB текущего браузера/сайта; после перезагрузки восстанавливает проект. Используйте один и тот же браузер и URL. Для локальной копии с `file://` сохранение зависит от настроек браузера; рекомендуются GitHub Pages и обычное окно браузера (не инкогнито). 

Доступны индикатор сохранения и кнопка «Очистить проект». Для дополнительной страховки выгружайте JSON. Хранилище может быть очищено браузером, квотой или пользователем. **Данные, потерянные до внедрения автосохранения, автоматически восстановить нельзя.**

## Videomaker Studio v3 — папки, умная подгонка и ZIP для ChatGPT

- **📁 Загрузить целую папку**: выберите папку, содержащую MP4/MOV/WebM и WAV/MP3/M4A. Видео добавляются по именам в естественном порядке, первая найденная музыкальная дорожка загружается в проект. Данные остаются локальными в браузере.
- **✦ Умная подгонка стыков**: браузер сравнивает уменьшенные изображения на границах двух видео, пробует несколько точек обрезки в пределах приблизительно 1,4 сек с каждого края и выбирает наименее отличающиеся по цвету/композиции. Затем предлагает краткое растворение или жёсткую склейку. Кнопка **«Отменить подгонку»** возвращает предыдущие обрезки. Это алгоритмический черновой монтаж, **не** распознавание содержания песни, сюжета, направления камеры или трёхмерной геометрии.
- **Увеличение в конце клипа**: выберите клип и задайте конечный масштаб, левую/центральную/правую точку фокуса, длительность анимации. Эффект действует в предпросмотре, WebM и Python-рендере.
- **↓ Пакет для ChatGPT ZIP**: скачивает исходные видео, аудио и проект JSON. Никакие медиа не публикуются в GitHub. Загрузите ZIP непосредственно в чат, чтобы ChatGPT мог проанализировать видео и создать исправленный монтаж. Из-за ограничений ZIP без Zip64 пакеты больше ~3,5 ГБ следует делить; ещё могут действовать лимиты прикрепления файлов в чате.
- **render_project.py**: при установленном FFmpeg позволяет собрать 1080p H.264 MP4 из пакета:
  ```bash
  python render_project.py Videomaker_for_ChatGPT.zip -o film.mp4
  ```
  Опции: `--width`, `--height`, `--fps`, `--crf`. Учитываются обрезки, тип переходов, плавный зум и фоновая музыка.
- **Автосохранение** предыдущих версий сохраняется в IndexedDB текущего сайта/браузера. Для надёжности периодически выгружайте резервную копию проекта/пакета.

**Ограничения:** ChatGPT не получает автоматического доступа к локальным файлам браузера, и GitHub сам по себе не предоставляет такой доступ. Для моего ручного профессионального монтажа передайте ZIP сюда. Автоалгоритм визуального сравнения полезен как старт, но может ошибаться, когда две сцены имеют одинаковые цвета и разные объекты. Зум не создаёт настоящего движения камеры за зданием; бесшовность нужно оценивать на готовом видео. Работа в браузере зависит от поддержки видеокодеков и памяти компьютера.

## Videomaker Studio v4 — реальная интеграция Montage AI

В этой версии изменён дизайн монтажной: медиатека слева, большой видеомонитор, таймлайн, инспектор стыков, настройки зума и новая панель Montage AI. Сохранены импорт папки, музыка, автосохранение в IndexedDB, экспорт WebM, PNG-отчёты и ZIP для ChatGPT.

**Исправление переходов:** кнопка «Подобрать границы» теперь ищет места жёсткой склейки, не добавляя автоматически растворение между кадрами похожих цветов. Это сознательно ограниченный алгоритм, а не полноценное распознавание движения камеры.

**Монтажный движок:** подключение к официальному REST API Montage AI: проверка `/api/status`, загрузка `/api/upload`, создание задачи `/api/jobs`, опрос `/api/jobs/{id}`, скачивание `/api/download/{filename}`. Браузер использует локальный безопасный мост `launch_studio.py`, который доступен только на компьютере пользователя (`127.0.0.1:8765`).

### Windows — установка и запуск

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/), [Git](https://git-scm.com/downloads/win) и [Python](https://www.python.org/downloads/windows/).
2. Откройте PowerShell или Git Bash:
   ```powershell
   git clone https://github.com/mfahsold/montage-ai.git
   cd montage-ai
   bash scripts/setup.sh
   docker compose build
   docker compose up
   ```
   Для команды `bash` используйте Git Bash или WSL. Подробности: [Montage AI Getting Started](https://github.com/mfahsold/montage-ai/blob/main/docs/getting-started.md).
3. В другом окне терминала откройте папку **Videomaker** и запустите `start_windows.bat` либо `py -m pip install -r requirements-bridge.txt`, затем `py launch_studio.py`.
4. Откройте `http://127.0.0.1:8765`. Нажмите **«Проверить подключение»**. Montage должен отвечать на `http://127.0.0.1:8080/api/status`.
5. Импортируйте исходные видео и музыку, выберите стиль и нажмите **«Создать монтаж через Montage AI»**. Результат можно скачать как MP4 после завершения задачи.

### Ограничения

- GitHub Pages продолжает работать как самостоятельный браузерный редактор, но *не может запустить локальный Docker* без локального моста. Для Montage используйте адрес `127.0.0.1:8765`.
- Монтаж Montage AI создаёт отдельную версию и может изменить сюжетный порядок сцен; существующий таймлайн Videomaker не перезаписывается.
- Подсказки в поле режиссёрского задания необязательно исполняются, если в Montage не настроена языковая модель. Локальные ритмические и монтажные алгоритмы работают отдельно.
- Montage AI не генерирует новые видеокадры и не создаёт физически точные переходы за зданиями.
- Локальный мост протестирован на имитации API (загрузка, запуск, статус, получение MP4). Полный Docker-рендер на вашем Windows ещё не проверен.
- Для базовых локальных возможностей платный API не нужен, но дополнительные облачные или LLM-функции могут быть платными. В локальном мосту cloud acceleration отключена по умолчанию.
- Не публикуйте исходники с реальными людьми в публичном репозитории.
